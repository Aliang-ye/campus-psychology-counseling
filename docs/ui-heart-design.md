# 主页爱心形布局

主入口 [`Main.vue`](../psychology-frontend/src/views/Main.vue) 用爱心轮廓组织四个模块，突出心理咨询的温暖主题。

## 模块位置

| 位置 | 模块 | 路由 |
|------|------|------|
| 左上 | 个人中心 | `/profile` |
| 右上 | 心理测评 | `/assessment` |
| 左下 | 咨询服务 | `/consult` |
| 底尖 | AI 小助手 | `/ai-assistant` |

咨询服务中心再分出文章库、社区、一对一咨询大厅。

## 视觉与交互

- 主题色：玫红 `#ff4d7d`
- 背景：粉白到淡黄渐变
- 按钮：白色圆形 + 阴影；悬停放大上浮，点击轻微缩小
- 爱心轮廓：SVG 描边，缩放不失真

桌面 / 平板 / 手机通过媒体查询缩小容器和按钮尺寸。动画用 CSS transform，不额外依赖 JS。

本地预览：启动前端后打开 http://localhost:5173/main（需先登录）。
