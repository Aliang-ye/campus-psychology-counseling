# 原型图占位与命名规范

将各页面的原型图（PNG/JPG/SVG）放在本目录，命名示例：

- login.png
- main.png
- assessment.png
- assessment-history.png
- consult-ai.png
- consult-service.png
- community.png
- article-library.png
- profile.png

命名规则：`页面英文名-可选说明-版本-日期`，例如 `assessment-v1-20260112.png`。

建议在原型工具（Axure/Figma）中同时导出标注文件，以便开发对齐。
